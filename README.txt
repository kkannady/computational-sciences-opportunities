COMPUTATIONAL SCIENCES TALENT HUB - V2

To update your GitHub Pages site:
1. Open your computational-sciences-opportunities repository on GitHub.
2. Upload/replace these files in the repository root:
   - index.html
   - hero-science.svg
   - science-grid.svg
   - config.js
   - roles.json (optional; retained for reference)
   - google_sheet_template.csv (optional)
3. Commit the changes to main.
4. GitHub Pages will rebuild automatically.

This version is self-contained and uses local SVG artwork, so it does not depend on external image hosts.
